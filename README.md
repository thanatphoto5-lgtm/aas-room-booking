# AAS CMU Room Booking

ระบบจองห้องประชุมภาควิชาสัตวศาสตร์และสัตว์น้ำ รุ่นทดลอง รองรับ GitHub → Netlify

**สถานะ:** ต้นแบบที่เก็บข้อมูลในเบราว์เซอร์ ยังไม่มีบัญชีเข้าสู่ระบบหรือฐานข้อมูลกลาง ข้อมูลไม่แชร์ระหว่างเครื่อง
GitHub เก็บโค้ด และ Netlify ให้บริการหน้าเว็บ การเชื่อมสองบริการนี้อย่างเดียวไม่ทำให้ข้อมูลการจองแชร์กัน

## 1. นำโค้ดขึ้น GitHub

1. แตก ZIP ชุดนี้ลงเครื่อง
2. สร้าง repository ใหม่ เช่น `aas-room-booking` ในบัญชี GitHub ของคุณ
3. เลือก Add file → Upload files
4. ลากไฟล์และโฟลเดอร์ **ภายใน** โฟลเดอร์ที่แตก ZIP ขึ้นไปทั้งหมด อย่าอัปโหลด ZIP เป็นไฟล์เดียว
5. ให้ `index.html`, `package.json`, `netlify.toml`, `app.js`, `core.js` อยู่ระดับแรกของ repository และเก็บ `vendor/` กับ `tests/` ไว้ครบ
6. กด Commit changes

หากใช้ Git CLI ให้เพิ่ม remote ของ repository ที่คุณสร้าง แล้ว push โค้ดไปสาขา main ตามคำแนะนำที่ GitHub แสดง
ไม่ต้องใส่รหัสผ่านหรือ token ลงในโค้ด

## 2. เชื่อม GitHub กับ Netlify

1. เข้าบัญชี Netlify ของคุณ
2. เลือก Add new project → Import an existing project → GitHub
3. อนุญาตให้ Netlify เข้าถึง repository ที่ต้องการ แล้วเลือก `aas-room-booking`
4. เลือกสาขาที่เก็บโค้ด เช่น `main`
5. ตรวจการตั้งค่าตามตารางนี้:

| รายการ | ค่า |
|---|---|
| Base directory | เว้นว่าง (ราก repository) |
| Build command | `npm run build` |
| Publish directory | `.` (จุดเดียว) |
| Node.js | 22 ตั้งไว้ใน netlify.toml แล้ว |
| Environment variables | ไม่ต้องกำหนด |

6. กด Publish/Deploy แล้วรอจนสถานะสำเร็จ เปิด URL ของ Netlify ที่ได้รับ
7. ครั้งต่อไปแก้โค้ดและ commit/push ไปสาขาที่เชื่อมไว้ Netlify จะเผยแพร่ใหม่อัตโนมัติ

ชุดนี้เป็น HTML/CSS/JavaScript แบบไม่ต้องแปลงโค้ด คำสั่ง build มีหน้าที่ตรวจไวยากรณ์และกติกาการจองก่อนเผยแพร่
ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม ไลบรารีอ่าน Excel รวมอยู่ใน vendor แล้ว

## 3. ทดลองใช้งาน

- เลือกห้องและวันที่ แล้วจองห้อง
- ไปเมนูจัดการห้องและคำขอเพื่อทดลองอนุมัติ
- เมนูนำเข้าตารางเรียน: ดาวน์โหลดแบบฟอร์ม กรอกข้อมูล เลือกช่วงเทอม อัปโหลด ตรวจสอบ แล้วกดยืนยัน
- ดูรายละเอียดรูปแบบไฟล์และการสำรองข้อมูลใน README_TH.md
- ความจุของห้องในชุดนี้เป็นค่าทดลอง ต้องตรวจสอบก่อนนำไปใช้จริง

## 4. ตรวจโค้ดบนเครื่อง

ใช้ Node.js 22 หรือใหม่กว่า แล้วรัน `npm run build` จากโฟลเดอร์โปรเจกต์
ไฟล์ไม่มีข้อมูลจองจริง ไม่มีรหัสผ่าน และไม่มีข้อมูลทดสอบของผู้ใช้ฝังอยู่

## ข้อจำกัด

- localStorage แยกตามเบราว์เซอร์และ URL ข้อมูลเดิมจะไม่ย้ายตามไป URL ใหม่
- ทุกคนที่เปิดเว็บทดลองสามารถเข้าหน้าเจ้าหน้าที่ได้ การตั้งชื่อไม่ใช่การเข้าสู่ระบบ
- ยังไม่มีการควบคุมการจองพร้อมกันระหว่างผู้ใช้หรือเครื่อง จึงใช้เพื่อทดลองรูปแบบและขั้นตอน
- ก่อนเปิดใช้ร่วมกันต้องเพิ่มฐานข้อมูลกลาง การเข้าสู่ระบบ สิทธิ์ และการตรวจเวลาทับซ้อนที่เซิร์ฟเวอร์
- ผ่านการทดสอบกติกาเวลาและการอ่าน Excel โดยตรง และทดสอบจอง/อนุมัติผ่านเบราว์เซอร์
- การทดสอบนำเข้า Excel ผ่าน UI ครั้งก่อนค้าง ยังไม่ได้ยืนยันตลอดเส้นทางบน Netlify จริง
- ชุดนี้พร้อมนำขึ้น repository แต่ยังไม่ได้ push หรือ deploy ไปบัญชีของคุณ

## ปฏิทินรวมทุกห้อง (รุ่น 1.1)
เปิดปฏิทินครั้งแรกจะแสดงทุกห้อง ทั้งรายการประชุมของผู้จองทุกคนในข้อมูลชุดนี้และตารางเรียน
ชื่อห้องปรากฏในแต่ละรายการ กิจกรรมต่างห้องที่เวลาเดียวกันแสดงเคียงกัน กดดูรายละเอียดได้
เลือกห้องจากตัวกรองเพื่อดูเฉพาะห้องได้ ในมุมมองทุกห้อง เมื่อเริ่มจองจะต้องเลือกห้องก่อนส่งคำขอ
ข้อมูลยังคงเป็นข้อมูลในเบราว์เซอร์เดียวกัน ไม่ได้ซิงก์ผู้ใช้งานจากเครื่องอื่น

## หน้าปฏิทินตามภาพอ้างอิง (รุ่น 1.2)
ปฏิทินเดือนด้านซ้ายพร้อมตัวบอกสถานะ ตารางเวลารายสัปดาห์ด้านขวา แถบสถานะในกล่องกิจกรรม
ช่องเลือกห้องด้านขวาบนแสดง (จำนวนที่นั่ง) ชื่อห้อง และเปลี่ยนรายการในปฏิทินทันที
ตัวเลือกทุกห้องแสดงกิจกรรมที่ทับเวลากันของแต่ละห้องเคียงกัน โดยแสดงรหัสห้องในแต่ละรายการ


## รุ่น 1.3 — หน้าผู้ยืมและเจ้าหน้าที่
ใช้โลโก้ AAS CMU ที่ได้รับ พร้อมธีมม่วง ทอง ฟ้า หน้า `#borrower` แสดงคำขอของฉันและปุ่มจอง หน้า `#staff` แสดงคำขอรออนุมัติและเครื่องมือจัดการ สลับบทบาทได้จากส่วนหัว เป็นเพียงการแยกหน้าจอ DEMO ไม่ใช่การยืนยันตัวตนหรือจำกัดสิทธิ์ฝั่งเซิร์ฟเวอร์ ข้อมูลยังเก็บเฉพาะเบราว์เซอร์เดิม
