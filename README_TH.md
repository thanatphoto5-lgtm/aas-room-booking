# ระบบจองห้องประชุม AAS CMU — รุ่นทดลองสำหรับ Netlify

## เริ่มทดลองบน Netlify
1. แตกไฟล์ AAS_CMU_Room_Booking_Netlify.zip จะพบ index.html, app.js, core.js, style.css, vendor/ และไฟล์แบบฟอร์ม
2. เปิด https://app.netlify.com/drop และเข้าสู่บัญชี Netlify ของคุณ
3. ลากโฟลเดอร์ที่มี index.html อยู่ข้างในทันที ลงในพื้นที่อัปโหลด ไม่ลากเฉพาะไฟล์ index.html
4. รอ Netlify สร้างเว็บไซต์ แล้วเปิด URL ที่ได้รับ
5. ถ้านำเข้าผ่าน Git ให้ตั้ง Publish directory เป็น . (จุด) และ Build command เป็น npm run build ตาม netlify.toml

แนวทางอ้างอิง: https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/
แพ็กเกจนี้ไม่มี API key และไม่มีขั้นตอนแปลงโค้ด คำสั่ง npm run build ตรวจไวยากรณ์และกติกาการจองก่อนเผยแพร่
ยังไม่ได้เผยแพร่ขึ้นบัญชี Netlify ของคุณจากแชตนี้

## ขอบเขตรุ่นทดลอง
- ดูตารางรายวัน สัปดาห์ เดือน และเปลี่ยนห้อง
- จองห้องพร้อมตรวจเวลา จำนวนที่นั่ง และรายการที่ชนกัน
- ส่งคำขอ รออนุมัติ อนุมัติ ไม่อนุมัติ และยกเลิกพร้อมเหตุผล
- เพิ่มห้องใหม่ และทดลองบทบาทเจ้าหน้าที่
- นำเข้า Excel .xlsx หรือ CSV ตามแบบฟอร์ม วนซ้ำคาบเรียนทุกสัปดาห์ตลอดเทอม
- เว้นวันหยุด ตรวจรายการชนก่อนบันทึก แทนที่ตารางเดิมตามภาคเรียน
- งดคาบเรียนเฉพาะครั้งได้ โดยกดคาบในปฏิทิน
- ส่งออก CSV สำรอง/กู้คืน JSON และดูประวัติการเปลี่ยนแปลง

## ข้อมูลและผู้ใช้งาน
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้เก็บที่ Netlify
ผู้ใช้คนอื่นหรือคนละเบราว์เซอร์จะไม่เห็นข้อมูลชุดเดียวกัน การเปลี่ยน URL เว็บก็จะใช้พื้นที่ข้อมูลอีกชุด
ชื่อผู้ทดลองใช้มีไว้แสดงผล ไม่ใช่การเข้าสู่ระบบ ไม่มีการบังคับสิทธิ์ ทุกคนที่ใช้เครื่องนั้นสามารถทดลองหน้าเจ้าหน้าที่ได้
การเปลี่ยนชื่อแสดงผลไม่เปลี่ยนเจ้าของรายการในเครื่องเดิม
การตรวจเวลาชนใช้ข้อมูลในเครื่อง ไม่สามารถรับประกันการจองพร้อมกันจากหลายเครื่องหรือหลายแท็บ
ใช้เพื่อทดลองขั้นตอนและรูปแบบหน้าจอก่อนใช้งานจริง
การล้างข้อมูลเบราว์เซอร์หรือใช้โหมดไม่ระบุตัวตนอาจทำให้ข้อมูลหาย ควรสำรอง JSON
ไฟล์ Excel อ่านในเบราว์เซอร์โดยไม่อัปโหลดไปเซิร์ฟเวอร์ ไฟล์สำรองอาจมีข้อมูลติดต่อผู้จอง
ค่าความจุ 30 ที่นั่งของ MTR2 และ 60 ที่นั่งของ AB2–003 เป็นค่าทดลอง ต้องตรวจสอบก่อนนำไปใช้จริง

## วิธีจองห้อง
1. กดชื่อผู้ทดลองใช้ด้านขวาบนแล้วตั้งชื่อ
2. เลือกห้องและวันที่ กดจองห้องประชุม หรือกดช่องเวลาว่าง
3. กรอกชื่อกิจกรรม ชื่อผู้จอง เบอร์ติดต่อ และจำนวนคน แล้วส่งคำขอ
4. เปิดเมนูจัดการห้องและคำขอเพื่อทดลองอนุมัติ
5. รายการจองของฉันใช้ดูสถานะ กดรายละเอียดเพื่อยกเลิกได้
รุ่นแรกยังไม่มีการแก้ไขวันเวลาในรายการเดิม ให้ยกเลิกแล้วจองใหม่

## วิธีนำเข้าตารางเรียน
1. เปิดเมนูนำเข้าตารางเรียน แล้วดาวน์โหลดแบบฟอร์ม Excel หรือใช้ AAS_Schedule_Template.xlsx ในแพ็กเกจ
2. แก้ไขข้อมูลตัวอย่างให้เป็นข้อมูลจริง โดยใช้คอลัมน์ดังนี้:
   รหัสวิชา | ชื่อวิชา | ห้อง | วันเรียน | เวลาเริ่ม | เวลาสิ้นสุด
3. ห้องใช้รหัสตรงกับหน้าจัดการห้อง เช่น MTR2 หรือ AB2-003 (ใช้ขีด - ปกติ)
4. วันเรียนใช้ชื่อไทย เช่น จันทร์ พุธ พฤหัสบดี หรือชื่อขึ้นต้น วันจันทร์
5. เวลาใช้ 09:00 และ 12:00 รองรับเซลล์เวลา Excel แบบตัวเลขด้วย เวลาเปิดใช้ 08:00–18:00
6. หนึ่งแถวแทนหนึ่งคาบประจำสัปดาห์ วิชาเดียวกันที่เรียนสองวันให้แยกสองแถว
7. เลือกภาคเรียนและวันที่เริ่ม–สิ้นสุด ปีในข้อมูลวันที่เป็น ค.ศ. ปฏิทินจะแสดง พ.ศ.
8. ใส่วันหยุดในรูป YYYY-MM-DD เช่น 2026-12-10 หนึ่งวันต่อบรรทัด
9. เลือกไฟล์ กดตรวจสอบและแสดงตัวอย่าง ตรวจจำนวนคาบและช่วงเวลา
10. ถ้ามีคาบชน ระบบจะไม่ยอมยืนยัน ต้องแก้ไขก่อน ไม่มีการข้ามคาบที่ชนอย่างเงียบ ๆ
11. กดยืนยันนำเข้า คาบเรียนจะแสดงสีม่วงและกันเวลาจอง

รองรับชีตแรกของไฟล์เท่านั้น หัวคอลัมน์ต้องอยู่แถวแรก ไม่มีเซลล์รวม ไม่มีหัวเรื่องเหนือคอลัมน์
รับไม่เกิน 5 MB และ 500 แถว ภาคเรียนไม่เกิน 370 วัน ไม่รับคาบย้อนหลังในรุ่นนี้
ยังไม่รองรับตารางแบบภาพ PDF ตารางไขว้ หรือไฟล์ที่ตั้งรหัสผ่าน
หากอัปโหลดซ้ำ ข้อมูลเดิมจะถูกตรวจพบว่าชนกัน เลือกแทนที่เมื่อต้องการแก้ไขตารางเดิม
ตัวเลือกแทนที่ครอบคลุมตารางเรียนของภาคเรียนนั้นทุกห้อง ต้องอัปโหลดข้อมูลให้ครบทุกห้องที่ต้องการเก็บไว้
การจองประชุมจะไม่ถูกลบ หากชนกับตารางเรียนใหม่ต้องจัดการก่อนนำเข้า

## ก่อนใช้งานร่วมกันจริง
ต้องพัฒนาและเชื่อมฐานข้อมูลส่วนกลาง ระบบเข้าสู่ระบบ สิทธิ์เจ้าหน้าที่ และการตรวจเวลาซ้อนแบบธุรกรรมบนเซิร์ฟเวอร์
รวมถึงทดสอบการจองพร้อมกันและการรักษาข้อมูลผู้จองก่อนเปิดให้บุคลากรใช้จริง
Netlify ใช้เป็นพื้นที่เผยแพร่หน้าเว็บได้ แต่การนำไฟล์นี้ขึ้น Netlify อย่างเดียวไม่ได้เพิ่มฐานข้อมูลส่วนกลาง

## การตรวจสอบรุ่นนี้
- ตรวจไวยากรณ์ JavaScript ผ่าน
- ทดสอบกติกาช่วงเวลา การทับซ้อน การยกเลิก วันหยุด และคาบซ้ำ ผ่าน
- อ่านไฟล์ Excel ตัวอย่างกลับและขยายคาบรายสัปดาห์พร้อมวันยกเว้น ผ่าน
- ทดสอบหน้าเว็บ เปิดแบบฟอร์ม ส่งคำขอ และอนุมัติ ผ่าน
- การทดสอบอัปโหลดผ่านเบราว์เซอร์ตรวจงานค้าง จึงยังไม่ยืนยันผลนำเข้าตลอดเส้นทางผ่าน UI
- ยังไม่ได้ทดสอบเว็บไซต์บนบัญชี Netlify จริง หรือทดสอบโทรศัพท์จริง
